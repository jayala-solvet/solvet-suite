# Titularidad y dependencias

Código específico preparado para el proyecto Solvet-IT. No se declara una licencia pública de distribución para ese código. Definir condiciones de uso y comercialización antes de entregarlo a terceros.

El esqueleto Laravel original y las dependencias conservan sus propias licencias y avisos. Revisar `composer licenses` y los textos originales de cada paquete antes de distribución comercial. El campo proprietary del proyecto no modifica las licencias de terceros.

Logo y referencia gráfica aportados por el usuario; se utilizan como identidad y referencia del proyecto. Odoo y ERPNext se citan únicamente como referencias de patrones de interacción.
