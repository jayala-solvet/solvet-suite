# Visión del producto

Solvet Gestión organiza el trabajo comercial y después operativo de una empresa de servicios informáticos. Solvet-IT es el primer usuario y el entorno donde validar la operación antes de vender el producto.

## Prioridades

1. Emitir una propuesta clara con identidad propia sin volver a escribir una planilla.
2. Encontrar documentos por cliente, referencia, fecha y estado.
3. Conservar qué se ofreció y qué respuesta se registró.
4. Añadir módulos sobre usuarios, clientes, permisos y documentos compartidos.
5. Mantener instalación, respaldo y actualización comprensibles para un equipo pequeño.

## Modelo comercial previsto

Instalaciones independientes por empresa, con la misma versión de código. Logo, condiciones y datos comerciales se configurarán por instalación. La marca del producto, la licencia y las condiciones comerciales de reventa deben definirse antes de distribuir fuera de Solvet-IT. Las bibliotecas conservan sus propias licencias.

Empresa usuaria/emisora y cliente comercial son conceptos distintos. `Company` representa el emisor único de una instalación; `Customer`, cada destinatario de propuestas.

## Fuera de la primera versión

ERP contable completo, facturación electrónica, manejo de inventario y compras, SaaS compartido multiempresa, aplicación móvil nativa y sustitución de GLPI. Las integraciones futuras no deben bloquear operaciones de presupuestos cuando el servicio externo esté caído.

## Decisiones abiertas

- Nombre definitivo del producto.
- Plantilla PDF definitiva y datos legales del emisor.
- Reglas finales para revisiones, aceptación por cliente y permisos granulares.
- Correlativo de inicio de operación real.
- Necesidades de facturación y moneda/tipo de cambio de cada cliente.
